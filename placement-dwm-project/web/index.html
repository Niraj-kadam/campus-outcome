About this project

From the project plan
Data warehouse

This dashboard presents the student placement analytics pipeline: a SQLite star schema, OLAP queries, preprocessing, exploratory analysis, decision tree classification, K-means clustering, Apriori rules, and BI exports.

Model interpretationSalary is left out of model features because it is zero for unplaced students and would leak the answer.
Cluster qualityK-means silhouettes are low (around 0.05), so the groups are broad profiles rather than clearly separated student types.

Refresh outputs after changing the source data with python run_all.py, then reload this page.
